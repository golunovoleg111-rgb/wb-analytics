# B-JOB Desktop

## Назначение

Windows-версия B-JOB запускает существующий frontend локально через Electron. Для запуска интерфейса не нужен GitHub Pages, VPN или внешний web-сервер.

## Сборка Windows

В GitHub Actions workflow `Build B-JOB Desktop` автоматически собирается NSIS installer. Артефакт workflow называется `B-JOB-Windows`.

Локально:

```bash
cd desktop
npm install
npm run build
```

Готовый установщик находится в `desktop/dist/`.

## Локальные данные

B-JOB использует IndexedDB. В desktop-режиме она хранится в профиле Electron приложения, а не в репозитории. Закрытие приложения не удаляет базу.

## Резервная копия

Экспорт desktop runtime создаёт JSON и отдельный `.manifest.json` с SHA-256. При импорте manifest проверяется, поэтому повреждённая копия не должна приниматься как корректная база.

Перенос:
1. Экспортируйте базу.
2. Скопируйте JSON и `.manifest.json` на флешку или по LAN.
3. Установите B-JOB на новом ПК.
4. Импортируйте JSON.
5. Проверьте товары, остатки, FBS-коробки и движения.
6. Старую копию удаляйте только после проверки.

## LAN

Один компьютер может выступать LAN-хостом. Доступ защищается случайным токеном. LAN не требует интернета. Обмен журналом операций использует уникальные IDs, чтобы повторно принятые операции не применялись второй раз.

LAN-обмен не должен молча перезаписывать конфликтующие изменения: конфликт должен быть явно показан пользователю и разрешён выбранным правилом.

## Финальная проверка

Используйте `FINAL_TEST.md`: там есть сценарии offline, backup/restore, LAN, повреждённой копии и конфликтующих изменений.

## Границы этапа

WB API и полностью автоматическая фоновая синхронизация с внешним сервером ещё не считаются реализованными. Никаких фейковых API или тестовых бизнес-данных не добавляется.
