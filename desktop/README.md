# B-JOB Desktop

## Назначение

Windows-версия B-JOB запускает существующий frontend локально через Electron. Для запуска интерфейса не нужен GitHub Pages, VPN или внешний web-сервер.

## Сборка Windows

В GitHub Actions workflow `Build B-JOB Desktop` автоматически собирается NSIS installer. Артефакт workflow называется `B-JOB-Windows`.

Локально:

```bash
cd desktop
npm install
npm run build
```

Готовый установщик находится в `desktop/dist/`.

## Локальные данные

B-JOB использует IndexedDB. В desktop-режиме она хранится в профиле Electron приложения, а не в репозитории. Закрытие приложения не удаляет базу.

Для резервного копирования используйте штатный экспорт JSON внутри B-JOB. Desktop runtime дополнительно предоставляет безопасный native bridge `window.BJobDesktop.exportJson()` и `window.BJobDesktop.importJson()` для последующего подключения к экрану резервного копирования.

## Перенос на другой компьютер

1. На старом ПК экспортируйте базу B-JOB в JSON.
2. Перенесите JSON на новый ПК через флешку или локальную сеть.
3. Установите B-JOB.
4. Импортируйте JSON через интерфейс приложения.
5. Проверьте товары, остатки, FBS-коробки и движения.
6. Только после проверки удаляйте старую копию.

Не копируйте вручную системные каталоги Electron.

## Автономный тест

1. Запустите B-JOB при наличии интернета.
2. Убедитесь, что интерфейс и локальные данные загрузились.
3. Отключите Wi-Fi/Ethernet.
4. Перезапустите B-JOB.
5. Проверьте товары, остатки, FBS и сохранение изменений.
6. Закройте и снова откройте приложение без сети.
7. Выполните экспорт JSON.
8. Включите сеть и убедитесь, что локальные изменения не исчезли.

## Границы этапа

WB API, LAN-синхронизация и автоматическое разрешение конфликтов не считаются реализованными этим этапом. Никаких фейковых API или тестовых бизнес-данных здесь нет.
