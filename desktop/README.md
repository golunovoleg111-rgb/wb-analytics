# B-JOB Desktop

## Что это

Windows-версия B-JOB с локальным runtime. Интерфейс загружается из локальных файлов, а данные хранятся в локальном браузерном хранилище приложения. Интернет не нужен для запуска интерфейса и работы с уже сохранёнными локальными данными.

## Сборка

Из каталога `desktop`:

```bash
npm install
npm run build
```

Результат: `dist/B-JOB-Setup-0.1.0.exe`.

## Установка

1. Запустить `B-JOB-Setup-0.1.0.exe`.
2. Выбрать папку установки.
3. Запустить B-JOB.
4. Проверить, что приложение открывается без интернета.

## Перенос данных

Пока web-версия и desktop-версия используют разные браузерные контексты, поэтому перенос между ними выполняется через штатный JSON backup/restore B-JOB.

На исходном компьютере: `Отчёты → Резервная копия`.

На новом компьютере после запуска B-JOB импортируйте полученный JSON через штатный импорт данных. Не копируйте вручную системные папки Electron.

## Тест автономной работы

1. Запустить B-JOB.
2. Импортировать небольшую реальную выборку данных.
3. Закрыть приложение.
4. Отключить интернет/Wi-Fi.
5. Запустить B-JOB снова.
6. Проверить товары, остатки и FBS.
7. Изменить один реальный локальный показатель.
8. Закрыть и открыть приложение повторно.
9. Проверить, что изменение сохранилось.

## Важно

Этот этап не притворяется готовой синхронизацией с WB или LAN-сервером. Они будут подключены поверх этого локального runtime следующим этапом. До этого момента источник данных в desktop-режиме — локальная база B-JOB.
