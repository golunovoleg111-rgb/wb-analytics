# B-JOB Desktop

## Что это

Windows-версия B-JOB с локальным runtime. Интерфейс загружается из локального приложения, а данные сохраняются в локальном хранилище B-JOB. Интернет не нужен для запуска интерфейса и работы с уже сохранёнными локальными данными.

## Сборка

Из каталога `desktop`:

```bash
npm install
npm run build
```

Результат: `dist/B-JOB-Setup-0.1.0.exe`.

## Установка

1. Запустить `B-JOB-Setup-0.1.0.exe`.
2. Выбрать папку установки.
3. Запустить B-JOB.
4. Проверить запуск без интернета.

## Перенос данных

Для переноса между компьютерами используйте штатную JSON-резервную копию B-JOB: `Отчёты → Резервная копия`, затем импортируйте JSON на новом компьютере через `Импорт данных`.

Не копируйте вручную системные папки Electron.

## Тест автономной работы

1. Запустить B-JOB.
2. Импортировать небольшую реальную выборку данных.
3. Закрыть приложение.
4. Отключить интернет/Wi-Fi.
5. Запустить B-JOB снова.
6. Проверить товары, остатки и FBS.
7. Изменить один реальный показатель.
8. Закрыть и открыть приложение повторно.
9. Проверить, что изменение сохранилось.
10. Экспортировать JSON и проверить импорт на втором профиле/компьютере.

## Границы текущего этапа

На этом этапе desktop runtime подключён к реальному frontend B-JOB и локальному хранилищу. Синхронизация с WB и LAN-сервер будут добавлены следующим этапом; здесь нет фейковых API или тестовых данных.
