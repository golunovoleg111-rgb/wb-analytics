# Финальная проверка B-JOB Desktop

## 1. Автономность
1. Установить B-JOB.
2. Запустить без VPN и без интернета.
3. Открыть FBS и существующие разделы.
4. Убедиться, что данные доступны локально.

## 2. Резервная копия
1. Экспортировать JSON.
2. Убедиться, что рядом создан `.manifest.json`.
3. Скопировать оба файла на флешку.
4. Импортировать JSON на втором ПК.
5. Проверить товары, остатки и FBS.

## 3. LAN
1. Два компьютера подключить к одной Wi-Fi/LAN сети.
2. На первом запустить LAN-хост.
3. Передать второму URL и токен.
4. Проверить соединение.
5. Выполнить push/pull данных.
6. Убедиться, что после отключения интернета LAN продолжает работать.

## 4. Целостность
1. Сделать копию JSON.
2. Изменить один символ в копии.
3. Импортировать её вместе с manifest.
4. Система должна отклонить повреждённую копию.

## 5. Конфликты
1. На двух ПК изменить один объект.
2. Обменять журналы.
3. Проверить, что конфликт не перезаписывается молча.
4. После реализации UI разрешения выбрать нужную версию явно.
