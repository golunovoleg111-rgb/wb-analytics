Manual checks after building the desktop app:
1. Start app and log in.
2. Confirm LAN button appears in desktop tools.
3. Start LAN server and verify URL/key are shown.
4. On a second computer in the same LAN, enter URL/key and save.
5. Test connection.
6. Export JSON backup before Pull.
7. Push supported stores to host and confirm no error.
8. Pull from host and confirm page reloads with host snapshot.
9. Export sync journal and confirm a JSON file is created.
10. Turn off internet and repeat LAN operations.
