# B-JOB Desktop 0.2.0 — quick release guide

1. Install the NSIS installer from the GitHub Actions artifact `B-JOB-Windows`.
2. Start B-JOB without VPN. The desktop runtime is local.
3. Export a JSON backup before moving to another PC.
4. Keep both the JSON and `.manifest.json` files together.
5. On another PC, import the JSON and verify products, stocks and FBS.
6. For LAN, connect both PCs to the same network, start the LAN host and use its URL/token on the second PC.
7. Use `FINAL_TEST.md` before putting the desktop build into warehouse work.
