# B-JOB Desktop release checklist

- Install the Windows NSIS artifact.
- Run without VPN/internet.
- Export JSON and keep its SHA-256 manifest.
- Import on a second PC and verify business data.
- Start LAN host on one PC and connect from another PC on the same network.
- Test push/pull and duplicate-operation protection.
- Test a deliberately corrupted backup and confirm rejection.
- Complete FINAL_TEST.md before warehouse deployment.
