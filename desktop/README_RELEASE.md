# B-JOB Desktop 0.2.0 — установка

- Установщик: GitHub Actions artifact `B-JOB-Windows`.
- Запуск не зависит от GitHub Pages и VPN.
- Перед переносом экспортируйте JSON и сохраните `.manifest.json`.
- На новом ПК установите приложение, импортируйте JSON и проверьте товары, остатки и FBS.
- Для LAN оба ПК должны быть в одной локальной сети; хост выдаёт URL и токен.
- Перед складской эксплуатацией пройти `FINAL_TEST.md`.
